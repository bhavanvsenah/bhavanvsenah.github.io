# Кельтский каталог и публикация Маккона

Кельтский каталог хранится в `celts.json`: `categories` → рубрики с
устойчивыми `id`, названиями и массивами `books`. В рубрике книги
сортируются по `sortAuthor` (фамилия первой), затем `author`; если автора
нет — по `title`. `author` остаётся читательским написанием. Анонимное
произведение не получает искусственного автора ради сортировки.

Рубрики можно раскрывать независимо. Используются нативные details/summary,
с анимацией открытия и закрытия. При reduced motion анимации нет;
при отсутствии Web Animations остаётся обычное раскрытие. Дхармический
каталог пока сохраняет прежний плоский формат массива.

## После каждого законченного переводческого пакета

1. В LGE завершить оба личных прохода, пересобрать мастер-свиток,
   проверить его и закоммитить перевод вместе с актуальным HTML.
2. В этом репозитории выполнить из корня:

   ```sh
   python3 tools/publish_mccone.py --revision <коммит-LGE> --date YYYY-MM-DD
   python3 tools/publish_mccone.py --revision <тот-же-коммит> --date YYYY-MM-DD --check
   python3 tools/stamp.py
   python3 tools/stamp.py --check
   ```

   Соседний репозиторий `../LGE` используется по умолчанию; другой путь
   задаётся через `--source-repo`. Импорт берёт только данные коммита,
   не незавершённые изменения в рабочей папке. Если HTML не соответствует
   MD в этом коммите, публикация останавливается. Дата — день публикации
   по времени пользователя.
3. Проверить каталог и открытие книги в браузере по HTTP, затем фиксировать
   только свои пути и отправлять ветку сайта. Сам импорт ничего не пушит.
   После него вручную поддерживай `robots.txt`, `sitemap.xml` и поисковые
   метатеги в `<head>` прямых страниц; тело страниц, JS и CSS не менять.
   Автор и коммитер — `bhavanvsenah
   <268193900+bhavanvsenah@users.noreply.github.com>`; push — только через
   аккаунт GitHub `bhavanvsenah`. Перед публикацией проверить `gh api user --jq .login`.
4. После сборки GitHub Pages проверить публичный каталог и файл книги.

При изменении `celts.json` или `dharma.json` выполнить
`python3 -B tools/catalog_discovery.py`, затем
`python3 -B tools/catalog_discovery.py --check`. Скрипт собирает из JSON
настоящие HTML-списки в существующих панелях `index.html` (Node.js нужен
для прежней сортировки через `Intl.Collator`). Названия и формат HTML —
обычные абсолютные ссылки `https://bhavanvsenah.github.io/...` на самостоятельные
страницы (в JSON остаются пути файлов репозитория); они доступны в первом
HTTP-ответе без выполнения JS. На стартовом экране новый список не появляется:
панели раскрываются и выглядят как прежде. `catalog.js` только добавляет
анимацию, а `app.js` перехватывает обычный клик для встроенного ридера;
модифицированный клик сохраняет обычную навигацию браузера.
Отдельного скрытого JSON-LD/noscript-каталога больше нет.
После изменения JS/CSS выполнить `python3 -B tools/stamp.py` и его `--check`.
Генератор включён в импорт Маккона.
GitHub Actions проверяет совпадение при push/PR, но без защиты ветки
не блокирует прямой push. Анонсы остаются в читательском каталоге без ссылки.

Проверка глазами простого HTTP-клиента (только базовый URL, без JS и без
заранее известных адресов книг):
`python3 -B tools/check_catalog_reader.py https://bhavanvsenah.github.io/`.
Она исключает scripts/noscript/templates, извлекает обычные ссылки каталога,
затем читает начало каждого найденного текста. Проверка не утверждает,
что любой сторонний ИИ обязательно использует такой же способ извлечения.

Артефакты: `celts/McCone-2005-ru.html` — автономный свиток;
`celts/McCone-2005-ru.publication.json` — коммит/хеши исходников, дата,
список опубликованных подразделов и хеш опубликованного HTML.
Редакторские MD, журналы, кропы и словари остаются в LGE и на сайт не копируются.

Маккон публикуется с явным статусом **«альфа-версия — перевод не завершён»**
и в каталоге, и в книге. Текст LGE не публикуется: существующая запись
остаётся недоступным анонсом без href и файлов форматов. Снятие альфа-статуса
и первая публикация LGE требуют отдельного решения пользователя.
